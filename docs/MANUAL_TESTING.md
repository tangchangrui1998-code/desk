# FoeDesk 完整人工验收

## 启动

```bash
cd app
pnpm dev
```

## 桌宠模式

1. 确认窗口透明、无边框、置顶且不出现在任务栏中。
2. 单击人物，确认快捷菜单展开；再次单击确认收起。
3. 按住人物移动超过 5 像素，确认窗口开始拖动且不会误触菜单。
4. 逐级测试 85%、100%、115%、130%、145%、160%、180% 和 200% 缩放。
5. 退出并重新启动，确认缩放和窗口位置恢复。

## 聊天与后台模式

1. 从快捷菜单进入“对话”，确认窗口扩展到聊天布局且仍显示人物。
2. 输入一条消息，确认未配置 Key 时仍有符合当前人物的离线回复。
3. 关闭对话，确认窗口恢复到原桌宠位置和尺寸。
4. 从快捷菜单进入“后台”，确认窗口居中并显示迁移概览。
5. 切换“始终置顶”，再点击“返回桌宠”，确认原位置恢复。

## 单实例与多显示器

1. 保持应用运行，再执行一次 `pnpm dev`，确认只保留一个窗口。
2. 最小化现有窗口后再次启动，确认已有窗口恢复并聚焦。
3. 在不同 DPI 的显示器间拖动，确认人物清晰且窗口逻辑尺寸稳定。
4. 把桌宠放在副屏后退出，拔掉副屏并重新启动，确认窗口回到可见工作区。

## 人物状态

1. 进入“后台 → 人物与外观”，在小野、莓莓、白桃和门后人偶之间切换。
2. 为四人分别设置不同称呼，返回桌宠确认气泡名称同步变化。
3. 为每人切换一套初始可用外观，检查头脚没有裁切且基线稳定。
4. 退出并重新启动，确认当前人物、称呼、关系状态和各自外观都保持不变。
5. 切换人物后确认另一人的外观没有被覆盖。

## 互动、情绪与记忆

1. 分别点击头部、上半身和人物轮廓外区域，确认对白和视觉反馈不同。
2. 快速重复点击同一区域，确认亲密度不会持续增加；等待冷却后可再次增加。
3. 分别测试单击、双击和拖动，确认不会互相误触。
4. 与两个人物分别聊天，确认历史互相隔离；输入“我叫…”或“我喜欢…”，重启后确认记忆仍在。
5. 在后台关闭“主动对白与提醒”，确认定时对白停止。

## 衣柜、暗号与主题

1. 确认未解锁暗号外观不会出现在衣柜。
2. 输入一条旧暗号，确认对应人物和外观立即解锁并切换。
3. 一次粘贴多条暗号及未知片段，确认有效暗号均解锁、未知片段被忽略。
4. 重复输入已解锁暗号，确认不会产生重复记录并会切换到该外观。
5. 解锁 `EVA-02-ASUKA` 和 `EVA-00-REI` 后选择对应外观，后台主题设为“跟随外观”，确认分别切换赤红与蓝色主题，桌面透明窗口不受影响。

## AI 与凭据

1. 不配置 Key 时确认离线聊天完整可用。
2. 在“后台 → 对话服务”保存 Key 并测试，确认成功后可启用 DeepSeek。
3. 分别测试错误 Key、错误模型、断网、限流和超时提示。
4. 删除 Key 后确认自动回到离线模式，系统凭据库中不再保留该条目。
5. 检查 localStorage/导出状态，确认不存在 API Key。

## 资源

1. 逐人物浏览全部已解锁外观，重点检查非标准尺寸原画和 200% 缩放。
2. `月潮祭司` 为保留背景的 `backdrop` 外观，应显示为有边框的完整画面，而不是透明立绘。
3. 执行 `pnpm assets:validate`，确认 66 张运行图、66 张缩略图和 50 条兑换码全部通过。
